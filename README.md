# SSH Project

This project contains Bash scripts for SSH key management and remote server connection.

## Files

- `0-use_a_private_key` - Connects to a server using a private SSH key
- `1-create_ssh_key_pair` - Generates an RSA SSH key pair with 4096 bits and passphrase 'betty'

## Requirements

- Ubuntu 20.04 LTS
- All scripts are executable
- Uses `/usr/bin/env bash` shebang
